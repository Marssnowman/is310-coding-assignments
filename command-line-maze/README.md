# Wall Street Culture Maze - Chenglin Chu

## Theme

This maze explores how Wall Street is represented and shaped through popular culture, including movies, financial news, internet memes, social media, and retail trading communities.

## Goal

Start at the entrance and follow each clue until you reach the final solution.

## Starting Point

After extracting the maze, enter the `maze` folder.

Start here:

entrance\start.txt

## Useful PowerShell Commands

List files and folders:

Get-ChildItem

Move into a folder:

cd folder-name

Move back one folder:

cd ..

Read a text file:

Get-Content filename.txt

Show hidden files and folders:

Get-ChildItem -Force

## Windows PowerShell Users

Before solving the maze, run:

.\hide-dotfiles.ps1

If PowerShell blocks the script, run:

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

Then run:

.\hide-dotfiles.ps1

Good luck!
